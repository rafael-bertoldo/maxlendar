# QA — US-17 (remoção do assistente, 2026-11-28)

## Objetivo

Verificar que o assistente foi removido de backend e frontend, que não há chamada ou rota de interpretação disponível, e que os fluxos manuais de eventos, recorrência semanal, conflito `409` e lembretes continuam funcionando sem depender dele. Os registros de QA das histórias retiradas devem permanecer preservados como histórico.

## Escopo

- Critérios: `docs/product-backlog.md:253-276` (US-17) e atualização de US-16 em `docs/product-backlog.md:221-247`; ADRs 0009 e 0010 marcados como supercedidos e ADR 0011 preservado com ajustes.
- Código verificado: `apps/api` e `apps/web` (código ativo), rotas HTTP da API em execução e bundle de produção do web.
- Documentação de QA: [US-12](US-12.md), [US-13](US-13.md), [US-14](US-14.md), [US-15](US-15.md) marcadas como histórico/retirado; [US-16](US-16.md) com a reprodução HTTP via assistente marcada como histórica e os critérios dependentes do assistente retirados. Nenhuma evidência anterior foi apagada.
- Ambiente: Node `v22.23.2`, npm `10.9.8`; data da verificação 2026-11-28. API em desenvolvimento em `http://127.0.0.1:3000`; scripts temporários fora do repositório; banco local `apps/api/prisma/dev.db` para os fluxos de aplicação e lembretes. Nenhum cookie, sessão ou segredo foi registrado.
- **Nenhum arquivo de aplicação e nenhum documento vigente foram alterados por este QA; nenhum commit foi criado.** Apenas os relatórios de QA foram atualizados/criados.

## Evidências

1. `npm run typecheck && npm run build` exit 0. O build gerou `apps/web/dist/assets/index-Cb0ZhOF4.css` e `apps/web/dist/assets/index-CeP0VUlk.js`; a compilação do API e do web terminou sem erros.
2. `POST /api/assistant/interpret` retornou HTTP 404, com corpo `{"message":"Cannot POST /api/assistant/interpret","error":"Not Found","statusCode":404}` (registro em `/tmp/opencode/us17-assistant-404.txt`). O log `/tmp/opencode/maxlendar-api-us17.log` lista apenas rotas de `/api/auth`, `/api/events` e `/api/push`; nenhuma rota de assistente foi mapeada.
3. `GET /api/events` sem sessão retornou HTTP 401 confirmando endpoints manuais ainda montados, com corpo `{"code":"UNAUTHENTICATED","message":"You are not signed in."}` (registro em `/tmp/opencode/us17-events-unauth.txt`). O mesmo log confirma `POST`/`GET` em `/api/events` e `PATCH`/`DELETE` em `/api/events/:id`.
4. `git grep -i assistant` em apps/{api,web} sem ocorrências em código ativo (`git grep -i assistant -- apps/api apps/web` terminou com exit `1` e nenhuma linha). Módulo, controller, service, tipos, painel e cliente HTTP do assistente não estão presentes no código vigente.
5. bundle web sem “Assistente da agenda” e sem `/api/assistant`. A leitura dos dois arquivos em `apps/web/dist/assets` retornou `false` para as duas buscas em CSS e JS.
6. `node /tmp/opencode/qa-us17.cjs`: 5 assertions (helper de recorrência/expansão/exceção/DST). Primeira ocorrência de quinta às 10 em `America/Sao_Paulo` em `2026-12-03T13:00:00.000Z`; exceção `deleted` removeu `2026-12-03` e manteve `2026-12-10`; em `America/New_York`, `02:00` de 08/03/2026 (inexistente) foi deslocado para `2026-03-08T07:00:00.000Z` e `01:00` de 01/11/2026 (ambíguo) usou `2026-11-01T05:00:00.000Z`. Saída: `US-17 recurrence helper: 5 assertions passed`.
7. `node /tmp/opencode/qa-flow.cjs`: 11 assertions (criação recorrente, listagem, exceção, conflito 409, exclusão por ocorrência/série, rejeição de múltiplos weekdays). Criação com `byWeekday=[4]` gerou `source="recurring"`, `seriesId` e `version=1`; a listagem em 35 dias expandiu pelo menos quatro ocorrências; a edição com `scope="occurrence"` criou exceção sem alterar as demais; versão desatualizada da exceção retornou `409`; exclusão por ocorrência removeu apenas aquela data e exclusão por série removeu todas; `byWeekday=[4,5]` retornou `UNSUPPORTED_RECURRENCE`. Saída: `US-16 application flow: 11 assertions passed`.
8. `node /tmp/opencode/qa-reminders.cjs`: 3 assertions (horizonte 48h, lembrete enviado preservado). `rescheduleSeries` criou dois lembretes `pending` nos offsets de 10 e 1 minuto dentro da janela de 48 horas; após marcar o primeiro como `sent`, uma nova execução manteve `status="sent"` e o `scheduledFor` original, sem reenvio. Saída: `US-16 reminder horizon: sent reminder preserved, 3 assertions passed`.

O script antigo `/tmp/opencode/qa-us16.cjs` continha asserções do assistente e foi substituído, para QA de US-17, por `qa-us17.cjs`. Os scripts `qa-flow.cjs` e `qa-reminders.cjs` foram reexecutados sem alteração e continuam cobrindo os fluxos manuais de recorrência e lembretes.

## Veredito

**PASSOU — US-17 concluída.** O assistente não está mais presente no código ativo, na API ou no bundle; a rota de interpretação responde `404` e as operações manuais de eventos permanecem montadas e protegidas por sessão. Recorrência, exceções, conflito de versão e lembretes foram revalidados sem dependência do assistente. O histórico de US-12 a US-16 foi preservado com os critérios retirados devidamente marcados.

## Limitações

- Sem automação de navegador: não houve clique, navegação, foco, screenshot ou renderização real. A ausência de painel/botão “Assistente da agenda” foi verificada por código ativo e pelo bundle, não por inspeção visual.
- A checagem HTTP foi feita sem sessão: o `404` comprova a ausência da rota de interpretação e o `401` comprova que os endpoints manuais existem e exigem autenticação. Fluxos autenticados completos por interface não foram executados.
- Os fluxos de aplicação e lembretes rodaram no banco de desenvolvimento `apps/api/prisma/dev.db`, não em produção; o cancelamento/reenvio foi verificado por leitura do banco, sem entrega real de push.
- O scheduler permanece em processo único e best-effort; uma interrupção superior a 48 horas pode perder lembretes, conforme ADR 0011.
- Recorrência diária, mensal, data de fim, múltiplos dias por série e mudança de fuso na edição da série continuam fora do incremento.
- Os relatórios US-12 a US-15 e a reprodução HTTP via assistente em US-16 são registros históricos/retirados; não devem ser lidos como evidência de funcionalidade vigente.
